# Host guide

SafeTrust helps you list a place, receive bookings, and manage escrow safely.

## List a place

Set the details for your property, including price, availability, and guest rules. Make the listing clear so guests know what to expect.

## Receive a booking

When a guest books, the payment is held in escrow while the stay is pending. This helps protect both the guest and the host.

## Confirm the stay

Once the stay is complete, SafeTrust releases the funds from escrow. Hosts do not start this release. If something changes, review the booking status and reach out through support if needed.

## Keep things up to date

Update the listing details when availability or pricing changes. Clear, current details reduce confusion and support issues.
